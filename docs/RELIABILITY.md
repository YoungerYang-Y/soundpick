# 可靠性标准

项目尚未定义正式 SLO，也没有生产运行数据；不要把本地检查结果称为线上可用性或性能证明。

## 服务目标

| 服务 | 当前目标 | 验证方式 |
|------|----------|----------|
| Web 页面与登录 | 请求失败时返回明确错误；配置无效时启动失败 | 本地请求与配置校验 |
| 媒体任务 | 单次任务交付完整 MP3 与可用原视频 MP4；视频封装失败单独降级，失败时清理临时数据 | 服务层检查、媒体工具和端到端流程 |
| 健康检查 | `GET /healthz` 给出最小存活结果 | HTTP 请求 |

不设定未经测量的延迟、可用性或错误率数字。30 秒不是产品硬指标。

## 任务与资源边界

工程默认值可配置，不代表用户产品硬指标或性能承诺：

| 项目 | 默认值 |
|------|--------|
| 输入容量 / 时长 | 200 MiB / 1800 秒 |
| 上传时限 | 300 秒 |
| 处理时限 | 600 秒 |
| 结果保留 | 3600 秒 |
| 普通请求体接收总超时 | 15 秒（`REQUEST_BODY_TIMEOUT_SECONDS`，范围 1–60 秒） |

- 单实例内存任务状态已实施，不跨重启或多实例存续。
- 一个活动任务，最多 32 个保留任务；同一目录有进程锁。
- 所有终态计入容量和到期回收。
- 允许 `sessionStorage` 时，同一标签页刷新可查询当前任务并恢复未过期结果。
- 恢复仅保存任务标识与确认/取消意图，不重传视频，不作为处理历史。
- 存储被禁用时退回当前页面流程。
- 同 ID 重放必须匹配创建时的输入类型和规范化分享链接；冲突不改动原任务或中断接收。
- 浏览器查询成功后，迟到的创建响应不得覆盖最新结果。
- 预约恢复只发起一次上传；待补发的取消仍需确认。
- 成功仅保留 MP3 与可用 MP4；失败/取消删全目录。
- 两种结果到期拒绝新请求，共享活动下载引用；最后一个响应结束后清理。
- 磁盘清理失败周期重试，下次启动清理专属残留目录；不触及其他用户数据。
- 任务状态仍在内存中，重启不恢复任务；`REDIS_URL` 配置后由 Redis 保存保护账本，正常跨重启保留依赖部署者启用 AOF 或 RDB。
- 每日成功额度为北京时区全站 10 首；pending 跨日占额、成功归完成日，失败/取消/预约超时/重启中断释放预约。Redis 可用时成功记录保留最近 7 天、限频最多 1 小时；额度与限频请求限额不变。
- Redis 未配置时使用内存保护；Redis 故障会在有界超时后自动降级到内存，服务继续运行。进程内限频最多保存 4096 个桶，额度记录另设 4096 条上限，不淘汰已有 key；容量耗尽时拒绝新 key。故障期间的请求仍按原窗口限频，但这些限频事件不会回灌 Redis。
- 进程保留已知额度和 pending 状态；Redis 恢复时通过 Lua 原子合并成功 ID 与当前 pending。故障期发生重启可能丢失内存额度并超过每日 10 首；恢复合并后如果额度已超限，则阻止新任务。Redis 恢复不清空继续有效的内存频率窗口。
- `REDIS_TIMEOUT_SECONDS` 默认为 0.1 秒，严格设置连接与套接字超时且不启用客户端自动重试；`REDIS_RETRY_SECONDS` 默认为 30 秒，用于故障熔断后的恢复探测。该超时并非请求总耗时：DNS 解析和多地址尝试可额外耗时。单实例和单进程锁继续成立；同一 Redis prefix 不支持多应用实例共享。
- 接口 429 包含 `Retry-After`，JSON 另含 `retry_after`。旧 SQLite 文件不会迁移或自动删除。
- 解析不到确认为原音轨的内容时，应明确失败，不能静默返回不匹配媒体。

- Redis 暂不可用时，失败路径仍清理媒体并立即释放本地 pending；Redis 恢复时仅合并成功 ID 和当前活动 pending。故障期若进程重启，内存成功记录可能丢失并造成额度短时超额。

## 可观测性

- 记录任务阶段和错误类别以便排障。
- 不记录共享密码、Cookie、完整分享文本或媒体内容。
- 当前尚未配置集中式日志、追踪、指标或告警；不要求引入未使用的观测平台。

## 故障处理

- 外部平台不可达、链接失效、媒体格式不支持、存储异常或转换失败：页面给出可理解的错误并回收输入。
- 接收中断、取消和任务超时：释放繁忙槽。
- 启动前运行 `make runtime-check`，确认 FFmpeg/FFprobe 真正可执行且有 MP3 编码器；缺工具不接受新任务。
- 真实平台、真机及容器证据不能由替身测试替代。

- Web 启动时也执行有界媒体运行检查，并缓存能力结果。
- 工具未就绪时保留 Web 页面与存活检查，拒绝新媒体任务。
- 检查失败或工具被替换后，需修正环境并重启。
- DNS 首地址连接失败时尝试其他经校验的公网地址；已响应或已开始下载的请求不重放。
