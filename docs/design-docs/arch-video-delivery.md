# 双媒体临时交付

日期：2026-10-03；状态：verified（本地实现与工程检查）。需求授权来自本轮用户补充“原视频也可以下载 MP4 格式”。

## 决定

成功处理后保留同一任务的 MP3 与可用 MP4，覆盖此前“成功立即删除原视频，只保留 MP3”的临时文件策略。已是 MP4 时移动私有输入保留原字节，其他容器无损封装；不额外下载或重新编码。

两种结果共用 owner、保留截止时间、容量和活动文件发送引用计数；到期拒绝新响应，最后一个活动响应结束后清理整个目录。失败、取消、整体超时、关闭和重启均覆盖两种文件。

MP4 准备失败不抹去已成功的 MP3；页面明确 MP4 不可用。内存任务、单进程和已有分层不变。最多 32 个结果新增的视频保留容量有明确上限，磁盘占用会高于仅保留 MP3。
