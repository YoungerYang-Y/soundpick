# 核心信条

本项目采用以下工程原则指导跨功能的长期决策。修改这些原则时应先记录架构决策。

## 1. 仓库是协作事实来源

产品范围、架构边界与未决事项应记录在仓库中，避免依赖不可追溯的口头背景。

## 2. 约束边界，内部保持简单

明确路由、服务、解析器和媒体处理的职责；边界内优先使用简单实现，避免为尚未验证的规模提前引入基础设施。

## 3. 输入和副作用必须显式

链接解析、文件上传、外部请求与媒体转换都应有清楚的校验、资源限制和错误处理。

## 4. 数据按最短需要保存

共享家庭工具不需要账户和历史；媒体文件仅在完成当前操作所需的时间内作为临时文件保存。

## 5. 以原音轨正确性为核心

只有来源和内容得到验证时才能称为原视频完整音轨；无法确认时明确告知用户。

## 6. 浏览器能力如实呈现

系统分享、下载位置和移动端交互受浏览器及操作系统支持影响，产品不承诺无法控制的系统行为。
