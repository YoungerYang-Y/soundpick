# 任务确认、媒体有效性与可测试性

## Context

整仓审查发现：上传接收完成到202送达之间没有可恢复的任务标识；重复取消能打断子进程回收；MP4元数据不保证画面可解码。平台注册、交付格式与浏览器共享状态也增加了扩展和回归成本。本决策保留单进程、单活动任务和临时存储约束。

## Decision

### 创建确认与取消

浏览器使用 `crypto.getRandomValues` 生成32位小写十六进制任务ID。文件输入先发送 `POST /api/tasks/reservations`，JSON为 `{task_id,filename?}`，返回202 TaskView；确认预约后发送 `POST /api/tasks/{id}/upload` 原始视频流，返回202 TaskView。两步均校验认证和CSRF，流式入口按实际字节限制，不使用客户端文件名拼接存储路径。

同owner、同ID、同输入类型的预约重放返回已有任务；其他owner返回404。任务ID绑定创建时的输入类型，跨上传/分享类型重放返回409，分享任务不接收上传流。重复上传或终态上传返回409，不覆盖输入，不重启处理。预约占用单活动槽，未开始接收的预约在上传时限到期后失败并清理，入口校验和周期清理均执行该规则。结果保留规则沿用全部终态的TTL和容量上限。

分享输入仍使用 `POST /api/tasks/link`，可携带同样的 `task_id`；仅同owner、同ID、同规范化链接的重放返回已有任务且不重复启动。链接绑定只保留进程内SHA-256指纹，不向TaskView公开、不保存原链接；规范化主机名和默认端口、移除fragment，保留path和query。换链接需新ID，即使不同链接实际指向同一视频。无客户端ID的旧创建接口继续兼容，网页改用可恢复协议。

预约、创建或上传响应丢失时，网页保留ID并通过原任务查询/取消恢复。未知ID的404不代表尚在途的创建已经停止；网页保持未确认状态，创建响应到达后补发取消。仅收到服务端终态确认后恢复创建新任务操作，不重传不确定的上传。

查询成功后，以查询得到的状态为准，迟到的创建成功或错误响应不得覆盖视图、回退上传进度或清空已准备的分享文件。创建成功仍确认任务存在并处理待补发的取消；查询得到预约状态时只启动一次尚未开始的上传。

同一任务的取消请求共享一个取消操作；等待者断开不取消清理。媒体子进程创建和回收在独立受保护任务中完成，即使再次注入取消也先回收，再传播取消异常。

### 媒体有效性与交付

视频必须至少含一条非 `attached_pic` 画面流及声音轨道。MP3仍从第一完整音轨生成。准备MP4时，在处理超时内对实际MP4或无损封装结果的画面执行完整解码至null；该检查不改变交付字节。损坏画面导致MP4单独降级，有效MP3仍可下载；取消和整体超时仍删除全部媒体。

两种格式的固定存储名、MIME、后缀和附件策略由 `app/services/artifacts.py` 集中定义。TaskView兼容现有字段；文件引用覆盖响应构造和实际发送，构造失败也归还引用。关闭时立即使任务过期，但保留仍在交付的引用，最后一次交付结束后删除文件和任务记录。外部元数据规范化未配对Unicode代理字符，保留合法emoji。

### 平台与浏览器封装

`PlatformSpec` 是平台ID、名称、允许域名、解析器工厂和配置字段的唯一登记。URL识别、工厂装配、能力列表及任务解析共享同一catalog；真实第三Adapter测试验证完整路由。上游JSON集合字段校验后才迭代，畸形结构进入备用解析路径，精确原视频ID约束保持。

前端使用原生ES模块：`app.js` 管理任务与请求生命周期，`task-view.js` 负责呈现，`file-share.js` 管理有界MP3缓存和系统分享。页面暂停使旧请求失效，恢复后仅当前请求更新视图。模块不增加构建步骤。

### 诊断与测试

记录任务ID、阶段和受控错误类别；不记录异常原文、完整分享链接、标题、Cookie、密码或媒体内容。公开错误继续使用固定可读文案。

标准 `make test` 加载媒体工具配置并要求真实工具，缺工具明确失败；直接pytest仍可用于局部测试并明确报告跳过。`make coverage` 使用coverage.py测量应用Python语句及分支，综合覆盖门槛85%；该指标混合单测/集成测试，不包括JS及媒体子进程内部。`make ui-check` 跑模块语法和可控时序回归。

`make browser-check` 使用可配置Playwright/Chromium，启动独立回环HTTP服务和临时数据，验证真实上传、MP3试听加载、MP4原字节下载及202延迟送达时的取消；默认重复5轮，退出回收浏览器、服务和临时数据。它不代表iPhone/Android或系统分享验收。

## Consequences

文件输入增加一次小JSON预约请求，换取响应丢失后的可恢复取消。完整画面校验增加CPU与时间，仍受现有处理上限约束。无数据库、队列、历史记录、前端框架或动态插件加载；手机、实网平台和容器验收单独记录。
