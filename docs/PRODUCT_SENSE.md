# 产品思维

本文为产品取舍提供已确认的用户背景和原则；详细范围见 [requirements.md](./requirements.md)。

## 这个产品是给谁用的？

供项目所有者本人和家人使用。优先考虑手机浏览器中粘贴分享内容或选择本地视频、试听并保存的完整流程，同时支持桌面浏览器。

## 产品原则

1. **输出要忠实**：交付完整原音轨；无法确认是原音轨时，应报告失败或不支持，不能将背景音乐等素材冒充原声。
2. **操作保持简单**：一次只处理一个视频，不引入账号、历史、AI 去人声、裁剪或批处理。
3. **临时数据及时清理**：处理数据只为当前操作暂存，不把任务历史变成产品功能。
4. **手机优先但尊重浏览器边界**：试听和下载应可用；系统分享与文件保存按浏览器能力提供，不承诺特定分享目标或目录。

## 决策优先级

1. 原音轨正确性和用户数据安全
2. 单次处理的可靠性
3. 手机端核心流程完整性
4. 视觉与交互打磨
