1. 可运行且含 libmp3lame 的 FFmpeg 和 FFprobe：可提供现有绝对路径，或明确授权在项目 Git 忽略目录准备独立工具。依照 AGENTS.md 的安装边界，授权尚未收到，未下载或安装新工具。
2. 当前可用的火山分享链接或解析服务文档；密钥留在本机配置。现有公开旧接口无成功样本，不能用模拟响应代替平台可用性。
3. 真实手机访问环境，用于 iPhone/Android 保存和 HTTPS 系统分享验收。端口、反向代理或部署操作应按用户授权处理。

工具就绪后首先运行：

```bash
FFMPEG_BIN=/absolute/ffmpeg FFPROBE_BIN=/absolute/ffprobe make test
```
