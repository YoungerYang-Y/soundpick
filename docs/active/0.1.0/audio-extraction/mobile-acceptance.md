# 手机真机验收

范围与结果以 [行为规格](./spec.md) 和 [验收记录](./acceptance.md) 为准。用户已确认可提供 iPhone 与 Android，并授权临时局域网测试；HTTPS 系统分享留到后续验收。本文件提供操作步骤，不表示这些步骤已经通过。

## 当前入口

两台手机连接与电脑相同的 Wi-Fi，使用手机浏览器打开主代理给出的局域网地址。iPhone 使用 Safari，Android 使用 Chrome；如使用其他浏览器，请记录名称。登录使用本机 `.env` 中的共享口令；不将口令粘贴到验收结果。电脑和临时服务需要保持运行，地址以本次实际提供的地址为准。

## 每台手机的操作

1. 打开登录页并登录，确认首页完整显示，按钮和输入框可以操作，没有横向滚动。
2. 将 `https://v.douyin.com/DUMJbobJ4gY/` 粘贴到分享输入框，也可粘贴包含该链接的完整分享文字；点击提取，观察处理状态与最终结果。该真实火山版样本已经在后端实网验证，声音约 12.051 秒。
3. 播放声音，检查首、中、尾内容；拖动到靠近结尾后继续播放，确认没有明显缺音或跳转失败。
4. 点击“下载 MP3”，完成浏览器要求的下载操作。到手机的文件入口找到实际文件，确认名称以 `.mp3` 结尾，并从文件入口重新播放首尾声音。仅点击下载按钮不算保存验收通过。
5. 切换“本地视频”，选择一段手机上有声音的短视频，完成提取、试听和下载。核对声音与原视频一致，不能只验证分享链接一种输入。
6. 如果“粘贴”按钮不可用，在输入框长按选择粘贴，确认还能提交。当前局域网 HTTP 页面不验系统分享；确认常规下载与保存说明仍可用。

iPhone 下载后可从 Safari 搜索栏旁的下载入口查看，再到“文件”App 的下载文件夹寻找；默认可能位于 iCloud Drive，实际位置以手机设置为准。见 [Apple 下载查找说明](https://support.apple.com/zh-cn/102440)。Android Chrome 可从菜单的“下载内容”或手机文件管理器查看实际下载文件，见 [Chrome Android 下载说明](https://support.google.com/chrome/answer/95759?co=GENIE.Platform%3DAndroid&hl=zh-Hans)。

## 后续 HTTPS 分享

在经过授权的 HTTPS 入口上取得结果，先点击“准备分享文件”，准备完成后再点击“打开系统分享”。选择手机实际提供的保存或分享目标，再到目标应用检查文件；取消分享应保留下载入口并显示取消提示。HTTPS 入口、设备支持情况和文件目标验证分别记录，当前局域网结果不能代替这些证据。
