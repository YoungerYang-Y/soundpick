# MVP 行为规格

逻辑版本：0.1.0。范围依据：[`../../../requirements.md`](../../../requirements.md)。
目标：本人和家人在手机浏览器登录后，用分享内容或本地视频取得完整原音轨 MP3，试听并保存。

2026-10-03 新增同次处理的原视频 MP4 下载，完整行为见 [补充规格](../video-download/spec.md)。本规格的音频行为保持兼容，成功后的临时输入策略以该补充为准。

完整声音验收：已知样本在首尾包含可辨识声音，输出首尾均保留；时长允许 MP3 编码填充误差 max(0.25, min(2, 原声音秒数×0.005)) 秒。真实平台样本逐一核对视频ID、原视频时长与首尾声音，不以同名音乐或背景音乐证明原音轨。

## Behavior: 创建本地视频任务

- 正常：Given 已登录且无进行中任务，When 上传含视频和声音的 MP4，Then 接受一个任务，完成后可取得完整 MP3。
- 边界：Given 已登录，When 视频恰好达到配置的大小和时长上限，Then 可处理；超出任一上限则拒绝并显示限制。
- 异常：Given 已登录，When 上传文本、损坏媒体、无声音视频或空文件，Then 显示具体失败原因，不提供 MP3，不保留输入。

## Behavior: 创建分享内容任务

- 正常：Given 可访问的抖音或火山视频，When 粘贴单个链接或含该链接的分享文本，Then 处理该视频完整声音，显示标题及作者（来源提供时）。
- 边界：Given 整段分享文字，When 其中有两个不同链接或不支持的平台链接，Then 提示仅支持一个抖音或火山视频，不下载任意链接。
- 异常：Given 平台返回失效、权限或验证页面，When 提交分享内容，Then 提示链接无法解析，可以改上传本地视频，不冒充解析成功或返回背景音乐。

## Behavior: 查看进度

- 正常：Given 本浏览器创建了任务，When 等待处理，Then 显示接收、解析、下载、转换、完成之一以及明确失败信息。
- 边界：Given 已有一个进行中任务，When 再次提交，Then 提示稍后再试，已有任务继续执行。
- 异常：Given 未登录或另一个浏览器会话，When 请求任务或文件，Then 不返回该任务或文件。

## Behavior: 取消处理

- 正常：Given 进行中任务，When 点击取消，Then 停止处理并删除输入和未完成产物。
- 边界：Given 已取消任务，When 再次取消，Then 仍显示已取消，不生成新任务。
- 异常：Given 已完成任务或无效任务，When 取消，Then 返回已完成结果或任务不存在；不删除其他任务。

## Behavior: 试听与保存

- 正常：Given 完成任务，When 试听、拖动播放位置、下载，Then 返回 audio/mpeg，下载文件名以 .mp3 结尾，覆盖视频完整声音。
- 边界：Given 完成任务，When 文件仍在配置保留期内，Then 可反复试听下载；到期后提示已过期、需重新提取。
- 异常：Given 保存方式不受当前浏览器支持，When 查看结果，Then 仍提供常规下载和 iPhone 文件 App/Android 下载目录指引，不声称已下载成功。

## Behavior: 系统分享

- 正常：Given 浏览器支持音频文件分享且已准备文件，When 用户点击分享，Then 调起系统文件分享。
- 边界：Given 浏览器不支持文件分享或非安全页面，When 结果显示，Then 提供下载入口和保存说明。
- 异常：Given 用户取消分享或文件准备失败，When 分享结束，Then 保留下载入口，取消不显示成功。

## Constraints

- 一次处理一个视频；单实例同一时刻最多一个接收或处理任务，繁忙时不排队（家庭低并发范围）。
- 默认单视频 200 MiB、30 分钟；结果保留 1 小时，最多保留 32 个结果。它们是可调整的工程默认值，非原始用户硬性要求。
- 接收上传最长 300 秒，单任务处理最长 600 秒；不承诺 30 秒完成。
- 成功仅保留完整 MP3 与可用原视频 MP4，其他输入删除；失败或取消删除全部媒体。两种产物在同一保留期内用于下载，过期后删除；异常退出的残留在下次启动清理。
- 不新增账户、历史列表、批处理、剪辑、去人声或数据库。
- 完成验收包含真实本地媒体端到端、真实抖音及火山样本；替身或模拟响应不能证明平台已可用。手机真机与 HTTPS 系统分享另列证据。
