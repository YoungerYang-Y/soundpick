# 安全策略

本文记录当前应用的安全边界和后续实现必须遵守的要求。

## 认证与授权

- 使用一个共享密码登录，不建立个人账号或角色体系。
- 会话由服务端签名 Cookie 保护；Cookie 使用 HttpOnly、SameSite=Lax，生产环境必须 Secure。
- 登录/退出表单校验 CSRF token，任务写 API 校验 X-CSRF-Token。未认证请求不能创建任务或访问结果文件；任务所属 owner 在登录时随机生成，不同浏览器会话不能读取对方结果。
- `/login`、静态样式与脚本和 `/healthz` 可匿名访问；首页、能力、任务、文件（含 HEAD/Range）均需要登录。上传在读取任何文件块前验证登录和 CSRF。
- `/healthz` 只返回最小存活信息，不应返回配置、凭据或任务数据。
- 当前标签页的恢复记录只含随机任务 ID、创建确认标记和取消意图，不包含认证令牌、分享文字或媒体。恢复查询仍需当前会话授权；浏览器存储不可用不影响当前页面处理。
- 当前会话无服务端会话表，退出清除当前浏览器 Cookie。已复制的有效 Cookie 在到期前仍可能重放；更换共享密码或 Session 密钥可令已有认证失效。

## 用户输入与媒体处理

- 链接、整段分享文本和上传文件均为不可信输入；在处理前校验协议、来源、格式及大小。
- 任务 ID 绑定创建时的输入类型及分享链接指纹；跨类型或不同链接重放返回 409，其他会话仍优先返回 404。链接绑定仅保留进程内规范化 URL 的 SHA-256，不保存原链接、不向客户端公开指纹；分享任务在消费上传流前拒绝本地视频。
- 外部请求逐跳校验 http(s)、80/443、公网 DNS 全部地址，连接固定经校验的 IP 并保留原主机 TLS/Host，禁用环境代理。小响应默认2MiB，重定向最多5次；媒体流按实际字节计数。解析令牌只发给固定端点，不跟随重定向。
- DNS 多地址只在连接建立失败时回退，不重放 HTTP 响应或已开始读取的媒体流。每个重定向使用独立客户端，避免同 IP 不同域名之间串用上游 Cookie 或连接池。
- FFprobe/FFmpeg 使用参数数组，不经 shell；只允许 file/pipe 协议。验证容器magic、视频/声音流和时长，首条完整音轨转192kbps MP3，检查输出时长；probe输出限制64KiB/128流，输出容量按配置最大时长限额。取消和超时杀死并回收子进程。
- 任务目录700、输入和MP3/MP4为600；随机目录不使用上传文件名。成功只保留交付用MP3与可用MP4，失败/取消删除全部；两种文件到期回收，活动发送共用引用保护。MP4仅保留已验证的实际MP4或无损封装，限制输出容量为输入限额加1MiB；失败不将其他容器改后缀冒充MP4。清理失败保留有上限的待回收对象并重试，启动只清理本应用命名空间内的任务残留；不得记录原始分享文本、媒体内容、密码或 Session 密钥。
- 结果播放和下载必须绑定到当前授权任务，避免通过可猜测路径访问其他文件。

## 配置与部署

- `.env` 不纳入版本控制。`scripts/init_env.py` 不覆盖已有配置、不打印秘密，并为新文件设置用户私有权限。
- 共享密码和 Session 签名密钥必须满足长度校验，缺少或长度不足时拒绝启动；校验不评估人为设置的口令熵。
- 本地回环 HTTP 配置可将 `APP_ENV=local`、`COOKIE_SECURE=false`；对外部署应使用 HTTPS 并设置 `APP_ENV=production`、`COOKIE_SECURE=true`。Docker 最终进程以非 root 用户运行。
- 基础请求体上限16KiB；仅原始视频上传端点采用独立200MiB默认上限，流式实际计数并受上传超时控制。客户端Content-Length/MIME/扩展名均不作为真实大小和媒体格式证明。

## 检查清单

- 新增端点说明认证要求，受保护结果不能匿名读取。
- 所有外部输入经过边界校验，外部请求设置目标限制和超时。
- 命令执行不经 shell 字符串拼接。
- 日志和错误响应不暴露秘密、媒体地址、内部文件路径或原始用户内容。
- 临时文件在终止路径可清理，且不会进入静态目录或版本控制。
